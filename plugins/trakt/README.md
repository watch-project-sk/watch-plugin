# Trakt: recommendations and history

Recommendations, trending, related titles, watchlist, calendar, history import and scrobbling. Everything runs inside Lampa and talks to the Trakt API directly.

## Setup

1. Create your own application at https://trakt.tv/oauth/applications with the redirect URI `urn:ietf:wg:oauth:2.0:oob`.
2. In Watch Plugins enter its Client ID and Client Secret.
3. Press "Log in to Trakt" and enter the shown code at https://trakt.tv/activate.

Keys and tokens stay on your device only.
