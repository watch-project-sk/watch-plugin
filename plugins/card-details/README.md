# Card Details

Reshapes the movie card: the director is moved into the cast row as the first item, the tags block is removed and the discuss block is dropped.

Built as an addon for [Applecation](https://darkestclouds.github.io/plugins/applecation/applecation.min.js). The manager loads Applecation first when Card Details is enabled. If you already load Applecation yourself, switch the Applecation entry off.

Settings: none.
