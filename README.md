# Watch Plugins

Plugins for [Lampa](https://github.com/yumata/lampa) with one entry point.

## Install

In Lampa open Settings, Extensions, and add:

```
https://watch-project-sk.github.io/watch-plugin/watch-plugins.js
```

Restart Lampa. A **Watch Plugins** item appears in the menu and in Settings, where every plugin can be switched on or off.
