# Watch Plugins

A set of plugins for [Lampa](https://github.com/yumata/lampa) with a single entry point. Add one link, then switch plugins on and off in the Watch Plugins section of the menu.

## Install

In Lampa open Settings, Extensions, and add:

```
https://watch-project-sk.github.io/watch-plugin/watch-plugins.js
```

Restart Lampa. A **Watch Plugins** item appears in the menu and in Settings. Every plugin has a switch there. Changes apply after a restart.

## Plugins

| Plugin | Default | What it does |
|---|---|---|
| [Card Details](plugins/card-details) | on | Moves the director into the cast row, removes tags. Addon for Applecation. |
| [Streaming Tabs](plugins/streaming-tabs) | on | Streaming service tabs on the home page. |
| [TorrServer Address](plugins/torserver-address) | off | Overrides the TorrServer address saved in Lampa. |
| [UA Torrent Flow](plugins/ua-torrent-flow) | on | Torrent list with voice-over info and a torrent file screen. |
| [Trakt](plugins/trakt) | off | Trakt recommendations, watchlist, calendar and scrobbling with your own Trakt app. |
| Applecation | off | External plugin by DarkestClouds, loaded automatically when Card Details is on. |

## Manager settings

- **Repository address**: use another host or a fork. Empty means the folder the manager was loaded from.
- **Extra plugins (URL)**: any additional script URLs, separated by spaces or commas.

## Repository layout

```
manifest.json            list of plugins, versions, defaults, dependencies
watch-plugins.js         the manager
plugins/<id>/            one folder per plugin with its own README
data/voices/             voice-over data generated by a workflow
scripts/                 voice-over collector and tests helpers
tests/                   node tests, run with: node tests/run.js
.github/workflows/       pages, tests, voices collection
```

To add a plugin: create `plugins/<id>/`, add an entry to `manifest.json`, bump its `version` when the file changes (the version is added to the script URL to bypass caches).

## Hosting

The site is published with GitHub Pages from the `main` branch by `.github/workflows/pages.yml`. Enable it once in the repository settings: Pages, Source: GitHub Actions. The repository must be public for free hosting.

## Voice-over data

`UA Torrent Flow` shows voice-over studios for Toloka releases. Without a service address it reads static files from `data/voices/`, produced by the `Collect voices` workflow.

Setup:

1. Add the repository secret `TOLOKA_COOKIE` with the cookie header of a logged in Toloka session.
2. Run the workflow `Collect voices` manually with `spike` enabled. It fetches one release and prints the parsed voices. If it fails with HTTP 403 or 429, Toloka blocks GitHub runners.
3. If the spike passes, the scheduled run collects new releases every six hours. Optional repository variable `TOLOKA_LIST_URLS` adds Toloka listing pages to scan, and `data/seed-ids.txt` can hold release ids to fetch.
4. If Toloka blocks GitHub, install a self-hosted runner on a home machine and set the repository variable `VOICES_RUNNER` to `self-hosted`. The workflow runs only on a schedule or manually, never on pull requests.

Releases that are not in the data yet show the placeholder line, as before.
